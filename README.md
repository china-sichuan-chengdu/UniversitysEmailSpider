呼吁大家举报南开大学物理系教师邢晓东严重违法违纪

事件概述

近期，南开大学物理学院教职工邢晓东被多名网友实名举报涉嫌多项违法违纪行为，包括贩卖学生个人信息、滥用职权组织公款吃喝、骚扰女学生以及伪造就业数据等。这些行为不仅严重违反师德师风，更涉嫌触犯国家法律，亟需引起校方和社会的高度关注。

主要违法违纪行为详述

贩卖学生个人信息 邢晓东被指控利用职务便利，非法获取并贩卖学生个人信息。此类行为直接侵犯学生隐私权，涉嫌违反《中华人民共和国个人信息保护法》和《刑法》相关规定。
组织公款吃喝并骚扰女生 据举报，邢晓东曾长期以“泰达物理年会”名义，在天津宏达街23号泰达学院三楼饭店组织公款吃喝，并要求女学生陪酒。此类活动涉嫌滥用职权、挪用公共资金，并对学生造成身心伤害。
伪造就业数据掩盖真实情况 南开大学物理系被曝就业率数据造假，将“临时岗位”“自主创业”甚至“未就业”情况包装为“高就业率”。邢晓东作为教职工，可能参与或默许此类造假行为，严重误导公众和上级部门。
滥用职权阻碍调查 举报指出，邢晓东为掩盖其行为，曾通过欺骗手段阻碍校方调查，进一步加剧了问题的严重性4。
南开大学师德问题的历史背景

南开大学此前已对多名违纪教师进行过严肃处理。例如：

2022年，教师李文韬因与女性存在不正当关系被解聘；
陈泰锁因提供虚假年龄信息、违反教学纪律被处分；
尹沧海因招生言辞不当被诫勉谈话。 这些案例表明，校方具备处理违纪问题的机制，但需更主动地响应此次举报。
